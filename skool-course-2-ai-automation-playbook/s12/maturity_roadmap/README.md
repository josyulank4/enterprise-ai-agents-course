# maturity_roadmap (s12)

**Section 12 — The Autonomous Enterprise + Capstone · Lessons 46–50**

The autonomous enterprise, staged — then prove the whole course shipped.

## Run

```bash
python demo.py
```

## What it does

1. **Maturity assessment** (Lesson 46) — five domains scored 1–5 map to the
   five stages: Manual → Assisted → Automated → Orchestrated → Autonomous.
   Fixture: orchestration is Orchestrated, governance is still Manual.
2. **Evidence gaps** — domains below target stage, or claiming a stage with
   no evidence on file (fixture flags `agent_workforce`, `data_foundations`,
   `governance`). A stage without evidence is a story, not a stage.
3. **Accountability-map template** (Lesson 47) — one name per box; a box
   with two names has no owner.
4. **Three-year roadmap template** (Lesson 48) — prove → scale → autonomy.
5. **Capstone checklist** (Lessons 49–50) — scans this repo and verifies
   all 13 section demos shipped `demo.py` + `README.md`. 13/13 = PASS.
